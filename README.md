# Gentleman Frame

いわゆる紳士枠を表示するツール

---

## 機能

- 動画
  - 動画１（背景）と動画２（前景）の2レイヤー構成。MP4・画像のドロップまたは URL 指定で読み込めます。
  - 2本の動画を自動同期し、ズレが生じた場合はオフセットで微調整できます。
  - 背景・前景の入れ替え、表示/非表示、音量・ミュート調整に対応しています。
- マスク
  - 前景動画に重ねる切り抜きエリアを、位置・サイズ・形状（四角／円／ハート）で調整できます。
  - ぼかし・ピクセル化・枠線のアニメーションなども設定できます。
  - マウス追従モードでリアルタイムに動かしたり、ホバー中にホイールでサイズ変更もできます。
- フィルター
  - 明るさ・コントラスト・彩度・色温度・シャープネスなど多彩な補正を映像全体に適用できます。
  - ビネット・フィルム粒子・レターボックスなど雰囲気づくりの効果も搭載しています。
- プリセット
  - 現在の設定を名前を付けて保存・呼び出しできます。
  - フォルダで整理したり、共有コードや JSON ファイルでエクスポート／インポートできます。

> [!WARNING]
> プリセットはブラウザの **localStorage** に保存されています。
> ブラウザのキャッシュ・サイトデータをクリアすると**すべて消えます**。
> 大切なプリセットは定期的にプリセットパネル右上の **↓ ボタン（JSON 保存）** でバックアップしてください。

## ショートカット

### キーボード

| キー | 動作 |
| --- | --- |
| `Space` | 再生 / 一時停止 |
| `←` / `→` | 1秒シーク |
| `Shift` + `←` / `→` | 5秒シーク |

### マウス（キャンバス上）

| 操作 | 動作 |
| --- | --- |
| 右クリック | マスク追従モード ON / OFF |
| ホイール（追従中 or マスクホバー中） | マスクサイズ変更 |
| ホイールクリック（中ボタン） | 背景・前景入れ替え |
| ダブルクリック | フルスクリーン切替 |
