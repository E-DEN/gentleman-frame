# Gentleman Frame

いわゆる紳士枠を表示するツール

![デモ](demo.gif)

**<https://gentleman-frame.pages.dev/>**

---

## 機能

### 動画

- **2レイヤー構成**：背景と前景を重ねて表示
- MP4・画像をドロップまたは URL 入力で読み込み。iwara.tv の URL にも対応
- 2本の動画の再生位置をオフセット値に合わせて**自動補正**。オフセットスライダーで任意の時間差を設定可能
- 背景・前景の**入れ替え**、表示/非表示、音量・ミュート調整

### マスク

- 前景動画に重ねる切り抜きエリアを**ドラッグ**で移動・リサイズ
- 形状：**四角 / 円 / ハート / スマホ / メガネ**
- ぼかし・ピクセル化
- **マウス追従モード**でリアルタイムにマスク / アンカーがマウスカーソルに追従（右クリックでON/OFF）
- キャンバス上のホイール操作でマスクサイズ・ズーム倍率を調整（後述）

### フィルター（映像全体）

| カテゴリ | 効果 |
| --- | --- |
| 基本補正 | 明るさ・コントラスト・彩度・色相 |
| トーン | ハイライト・シャドウ・マット |
| カラー | 色温度・色かぶり補正 |
| 特殊 | 色収差・シャープネス・カラーフレア |
| 雰囲気 | ビネット・フィルム粒子・全体ぼかし |
| モーション | モーションブラー・フレームレート制限 |
| オーバーレイ | 雨エフェクト・レターボックス |

### プリセット

- 設定を名前付きで**保存・呼び出し**
- フォルダで整理
- フィルターの現在の設定を**カスタムプリセットとして保存**することも可能
- **共有コード**（短縮テキスト）または **JSON ファイル**でエクスポート／インポート

> [!WARNING]
> プリセットはブラウザの **localStorage** に保存されています。
> ブラウザのキャッシュ・サイトデータをクリアすると**すべて消えます**。
> 大切なプリセットは定期的にプリセットパネル右上の **↓ ボタン（JSON 保存）** でバックアップしてください。

### 言語 / テーマ

- 表示言語：**日本語 / 英語 / 中国語（簡体字）**（右上の言語ボタンから切り替え）
- JSON ファイルをドロップして**外部言語を追加**することも可能
- **ダーク / ライトモード**切り替え対応

## 使い方

習うより慣れよー。

### キーボード

| キー | 動作 |
| --- | --- |
| `Space` | 再生 / 一時停止 |
| `←` / `→` | 1 秒シーク |
| `Shift` + `←` / `→` | 5 秒シーク |
| `P` | スクリーンショット保存 |

### マウス（キャンバス上）

| 操作 | 動作 |
| --- | --- |
| 右クリック（切り抜き枠の上） | 枠をマウスに追従させる / 解除 |
| ホイール（枠ホバー / 枠追従中） | 枠サイズ変更 |
| `Ctrl` + ホイール（枠ホバー / 枠追従中） | ズーム倍率変更 |
| `Shift` + ホイール（ズーム操作時） | ズーム倍率を 0.5 刻みで変更 |
| ホイールクリック（中ボタン） | 背景・前景入れ替え |
| ダブルクリック | フルスクリーン切替 |

## プライバシー

iwara の URL を入力した場合、動画解決リクエストは [Cloudflare Workers](https://workers.cloudflare.com/) 経由で処理されます（[Cloudflare プライバシーポリシー](https://www.cloudflare.com/privacypolicy/)）。  
このツール自体がユーザーの個人情報を収集・保存することはありません。
